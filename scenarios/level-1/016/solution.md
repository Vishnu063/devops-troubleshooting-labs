# Solution · 016

## Diagnosis supported by supplied evidence

No available agent matches the job label.

## Investigate

Inspect queue reason, node labels, executor count, and agent connection logs.

Correlate timestamps and recent changes. A similar symptom in a real environment can have a different cause.

## Recovery

Reconnect the intended agent or correct the label mapping.

## Verify

A queued build starts on the expected agent.

## Prevent recurrence

Monitor agent availability and capacity.
