# Solution · 030

## Diagnosis supported by supplied evidence

The target group checks an incorrect path.

## Investigate

Inspect target health reason, health path, port, and direct application response.

Correlate timestamps and recent changes. A similar symptom in a real environment can have a different cause.

## Recovery

Set the intended health endpoint and keep meaningful success criteria.

## Verify

Targets become healthy and user traffic succeeds.

## Prevent recurrence

Keep application and infrastructure health definitions aligned.

## Interview follow-ups

- What evidence would invalidate this diagnosis?
- What availability or data risk does the repair introduce?
- How would you roll back if verification fails?
- What would you tell the incident commander in 60 seconds?
