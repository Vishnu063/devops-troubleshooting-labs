# Security

Do not post real credentials, customer data, or internal production logs in issues. Reproduce with synthetic values.

If you find a security problem in a lab runner, use GitHub private vulnerability reporting if the repository has it enabled. Otherwise contact the repository owner privately through their published profile contact details before posting sensitive exploit details publicly.

If a real credential has been exposed, revoke it immediately and investigate its use. Removing a file from the latest commit does not revoke a credential or remove it from history.
